# QA Web Testing Portfolio

This repository showcases my practical experience in Software Quality Assurance (QA) through a web application testing project.

## Project Overview
Performed end-to-end testing on a web-based application focusing on authentication and CRUD functionalities to ensure system reliability and usability.

## Scope of Testing
- Authentication (Login & Register)
- CRUD Operations
- Input Validation
- User Workflow (End-to-End)

## Testing Activities

- Performed manual and regression testing

- Identified and reported 12+ bugs (UI, functional, validation)
- Created structured bug reports
- Validated system functionality across multiple scenarios

## Testing Approach

- Regression Testing
- End-to-End Testing
- Black-box Testing
